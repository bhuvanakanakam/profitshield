# ProfitShield × NOVA 2026

A participant pitch deck for the DoorDash Back House theme. Uses NOVA's public
blue/pink/orange palette with ProfitShield product visuals; not an official
event template or endorsement. All example amounts are synthetic.

- **[PowerPoint](ProfitShield-NOVA-2026.pptx)** — 10 editable widescreen slides,
  speaker notes embedded; eight pitch slides + two appendix slides.
- **[PDF](ProfitShield-NOVA-2026.pdf)** — portable presentation/export.
- **[Browser deck](presentation.html)** — download this folder, then open the HTML.
  Arrow keys, previous/next, notes and fullscreen controls. GitHub itself displays
  HTML source; it does not run the presentation.
- **[Speaker notes](SPEAKER_NOTES.md)** — roughly four-minute pitch including live
  demo, fallback plan, claims to avoid and source references.
- **[Repository map](REPOSITORY_MAP.md)** — all five upstream branch heads,
  architecture, current differences, tested status and next integration steps.
- `slides.json` — plain editable slide content for reuse.
- `assets/workspace.png` — real screenshot of the UI branch's synthetic demo.

Test with `feat/uiux-latest@7c5b6c6`. This documentation branch is based on
`development@5ed85b8`. It documents the separately tested UI branch and does not
alter application files, merge branches or deploy anything.
Open the PPTX in PowerPoint, Keynote, LibreOffice, or import it into Google Slides.

NOVA reference: https://nova.scottylabs.org/. Track text was supplied by the
participant in this conversation. Repository review snapshot: November 7, 2026.
